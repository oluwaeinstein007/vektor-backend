# Asset Tasking & Response SOP 4-2

## Asset Matching

A recommended Course of Action must only list required assets that exist in
the current blue-force asset inventory and are not already committed to a
higher-priority tasking. An option that requires an asset class not present
in inventory (for example, requesting fixed-wing CAS when none is
registered) should be flagged as INFEASIBLE rather than presented as a
viable option.

## Response Time Bands

Asset response time is grouped into three bands for planning purposes:
IMMEDIATE (assets already airborne or within 5 minutes of tasking),
SHORT-NOTICE (assets on ready alert, 5-30 minutes), and PLANNED (assets
requiring tasking-order lead time, 30+ minutes). Every COA option's
estimated_duration_min should be consistent with the response band of its
listed required assets, not an optimistic best case.

## Multi-Domain Coordination

When a recommended action spans more than one domain (e.g. an ISR asset
cueing a ground response), the COA rationale must name the coordination
mechanism between the domains, not just list both assets independently.

## Escalation

A target that has been actively tracked and unactioned for longer than the
configured escalation threshold should be flagged for command attention
regardless of its current threat score — a persistent but stationary
contact can represent as much risk as an actively maneuvering one if it
goes unaddressed.
